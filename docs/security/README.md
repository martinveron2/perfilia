# Security and Privacy

Security is a product requirement, not a post-MVP task.

Key rules:

- Never commit secrets, tokens, passwords, or private keys.
- Minimize personal data collection.
- Separate development, staging, and production.
- Apply least-privilege access.
- Protect personal data in transit and at rest where appropriate.
- Provide user-controlled export and deletion capabilities.
- Treat external job descriptions and other user-provided content as untrusted input.
- Review privacy and regulatory requirements before commercial operation in each jurisdiction.
